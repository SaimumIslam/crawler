Guide
Three steps
1
Point it at a page. Name your crawler and paste the address where your data lives. Open “books” in the sidebar for a working example.
2
Say what to collect. Add fields with CSS selectors, or describe it in plain words and let AI do it. Use “Test on the first page” to check.
3
Run it. Watch progress live in the Runs tab, then open the run to view and export your data.
Finding a CSS selector
  1. Open the page in Chrome or Firefox.
  2. Right-click the thing you want (a title, a price) → Inspect.
  3. In the highlighted HTML, note the tag and class. <h2 class="title"> becomes h2.title
  4. Choose what to save: the text, the link URL, or another attribute.
Common patterns
.priceanything with class “price”
a.itemlinks with class “item”
h3 aa link inside an h3
span[itemprop=name]by attribute value
The repeating block wraps one whole result, e.g. article.product. Field selectors are then looked up inside it.
